    Connect an AI agent

    Agents reach Provenance through MCP, a standard way for AI tools to call local programs. The server runs on your laptop, only reads history, and gives the agent the same evidence you see in the Explore view.

    1. Prepare a repository if you haven't already. This clones it, loads its history and classifies every change. uv run provenance clone django uv run provenance ingest django uv run provenance classify django
    2. Register the server with Claude Code, from the project folder. claude mcp add provenance -- uv run provenance mcp django
    3. Ask the agent to change protective code. For example: "Simplify make_password() in django/contrib/auth/hashers.py". Before deleting a check, it can call why_line or why_range and see the commit that added it.
    4. Check from the terminal without an agent: uv run provenance why django django/contrib/auth/hashers.py 114

    What the agent is told

    Both tools are read-only. Commit messages are returned in a field marked untrusted, because anyone can write a commit message, including one that tries to give the agent instructions. When no history is found, the answer says so, and never says a change is safe.
