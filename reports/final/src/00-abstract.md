The reason a line of code exists is usually written down: in a commit message, a bug ticket or a pull-request discussion. The standard tool for finding it, `git blame`, often points instead at the last commit that only reformatted, renamed or moved the line. As AI coding agents write more of the code that is merged, this gap matters more. An agent that cannot see why a check exists may delete it as clean-up.

This project builds and evaluates **Provenance**, released as the open-source tool and MCP server **whyblame**. A three-layer tracer classifies every file change in a repository's history as cosmetic, rename, move or logic, using tree-sitter token streams. It lets `git blame` look through each file's cosmetic commits, and steps through mixed commits line by line. On a held-out test set of lines from Django and Redis, it finds the right commit {{rq1.ours}} of the time, against {{rq1.b2}} for git's strongest settings (McNemar p < 0.001).

Each traced commit is linked to its discussion, across {{corpus.commits}} commits and {{corpus.discussions}} tickets, issues and pull requests in Django, Redis and React. When the link is missing, a time-respecting search finds the hidden ticket in the top ten for {{rq2.A.ours.recall@10}} of 1,000 Django commits. Explanations must cite their evidence or abstain. The explainer abstained on {{rq3.unanswerable_abstained}} of {{rq3.unanswerable}} questions whose evidence was withheld, and {{rq3.claims_supported_pct}} of the claims in its answers are supported by the evidence they cite.

A deterministic check warns when a change removes or weakens a guard whose history says it matters. It ships as a GitHub Action and was tested live on a real pull request. On held-out guard removals from 2020 on, its warnings are {{rq4.90.lift}} as likely as chance to hit a guard that later had to be restored ({{rq4.90.precision}} against a {{rq4.90.base}} base rate). In a controlled pilot on 16 real removals, an agent with the tool kept the guard in {{rq5.treatment.guard_kept}} of {{rq5.treatment.runs}} runs, against {{rq5.control.guard_kept}} without (McNemar p = {{rq5.guard_kept_mcnemar.p}}), and completed as many tasks. Everything runs on an 8 GB laptop: indexing Django's {{rq6.django.commits}} commits takes {{rq6.django.index_min}} minutes. Gold labels are AI labels, as disclosed throughout, and one script reproduces every number.
